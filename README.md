# BlogDeCafé

Blog estático dedicado al mundo del café: tipos de grano, recetas, beneficios, cursos y talleres. El proyecto está construido con HTML y CSS, sin dependencias ni procesos de compilación.

## Características

- Página de inicio con entradas de blog y cursos destacados.
- Sección **Nosotros** con información general del proyecto.
- Sección **Cursos** con talleres, fechas, precios y cupos.
- Página de **Contacto** con un formulario para enviar consultas.
- Diseño adaptable mediante hojas de estilo CSS.
- Navegación compartida entre las páginas principales.

## Páginas

| Página | Archivo | Contenido |
|---|---|---|
| Inicio | [`index.html`](index.html) | Entradas del blog y cursos destacados |
| Nosotros | [`nosotros.html`](nosotros.html) | Información sobre el blog |
| Cursos | [`cursos.html`](cursos.html) | Talleres y cursos disponibles |
| Contacto | [`contacto.html`](contacto.html) | Formulario de contacto |

## Tecnologías

- **HTML5** para la estructura del contenido.
- **CSS3** para el diseño y la maquetación.
- **Google Fonts** para las tipografías PT Sans y Open Sans.

## Ejecutar el proyecto

No se necesita instalar paquetes ni configuraciones adicionales.

1. Clona el repositorio:

```bash
git clone https://github.com/Gomezbj/blog-de-cafe.git
```

2. Entra en la carpeta:

```bash
cd blog-de-cafe
```

3. Abre `index.html` en tu navegador o inicia un servidor local:

```bash
python -m http.server 8000
```

Después, visita `http://localhost:8000`.
